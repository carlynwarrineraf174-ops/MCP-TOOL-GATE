## 2. P0-1 + P0-2 · 引擎的两个边界缺陷

### 2.1 现象（可复现，别凭我一句话）

```powershell
cd D:\Python\Project\mcp-tool-gate
python -m gate.check --base snapshots/real-v1 --head snapshots/real-v2
```

现在的输出：`BREAKING=3 RISKY=1 SAFE=1`（共 5 条），但 `examples/break_real.py` 明明白白注入了 **6 处**。

漏掉的是：

```text
boom.reason :  {"type":"string","default":"fail"}  →  {"type":"string","default":"fail","enum":["error"]}
```

老调用方可以传任意字符串，新契约只允许 `"error"` —— 这是**请求侧的收窄**，本该 BREAKING，但引擎输出 0 条。

同一根因还有两处（我用 6 行脚本探出来的，见 §2.5 的探针）：

| 变更 | 语义 | 现在的输出 |
|---|---|---|
| 老无 `enum`，新增 `enum:["error"]` | 收紧 | 无 |
| 老无 `type`，新增 `type:"string"` | 收紧 | 无 |
| 老无 `items`，新增 `items:{...}` | 收紧 | 无 |

**反过来还有一个误报**：

```text
{"type":"string"}  →  {"type":["string","null"]}
```

加 `null` 是**放宽**（老调用方依然全部合法），现在却报 `type_changed / BREAKING`。

### 2.2 根因（三处“两边都要求存在”的守卫）

| 文件位置 | 现在的写法 | 为什么会漏 |
|---|---|---|
| `gate/diff.py:113` `_diff_enum` | `if not (isinstance(old_enum, list) and isinstance(new_enum, list)): return` | 老侧没有 `enum` 就直接 return，等于「从无到有」永远不判 |
| `gate/diff.py:230` `type` 比较 | `if old.get("type") and new.get("type") and ...` | 老侧没有 `type` 就整块跳过 |
| `gate/diff.py:265` `items` | `if isinstance(old_items, dict) and isinstance(new_items, dict)` | 同上 |

三个都是同一个思维定式：**「比较」被写成了「两者都有才能比」**。但 JSON Schema 的语义里，**没写 = 不限**，所以「从不限到有限」正是最典型的收紧。

#### ① 新增一个辅助函数（放在 `_canon` 之后、`# ---- 预处理` 之前）

```python
def _type_set(node: dict) -> set | None:
    """把 type 归一成集合：`"string"` 和 `["string","null"]` 要能比较。

    None = 这个 schema 没写 type（JSON Schema 语义：接受任意类型）。
    """
    t = node.get("type")
    if t is None:
        return None
    return set(t) if isinstance(t, list) else {t}
```

#### ② 替换 `_diff_node` 里那段 `type` 比较（原来的 3 行）

## 3. P1-1 + P1-2 · 评测口径与本地可运行

### 3.1 为什么必须改（现在这两个分数回答不了你自己的问题）

现在的 `gate/eval.py`：

```python
args_ok = False
if tool_ok:
    args_ok = all(...)      # 只有工具对了才累加
if args_ok:
    args_correct += 1
...
acc_args = args_correct / total          # ← 分母是 total
```

于是 `args_acc` 实际上是「**工具和参数都对**的比例」，与 `tool_acc` 强相关。你在规划文档里写的那句"`tool 0.9/args 0.1` 和 `tool 0.1/args 0.9` 均分一样但修法相反"，**当前实现给不出这个信息**。

三个数分开之后，同一个结果能读出三件事（下面是我实测跑出来的对比）：

| 场景 | 现在只有一个总分 | 改后 |
|---|---|---|
| 3 题，1 题选错工具、但参数值恰好对 | `args_acc 66.67%`（会被误读成"参数填错三分之一"） | `tool 66.67% / args 100% / both 66.67%` → **会挑工具差，会填参数好**，该改工具描述 |

### 3.3 动作 2：把 `gate/eval.py` 整体替换为下面这版

> 这就是我在临时副本里跑通的版本（42 tests、三个分数输出如上）。**整文件替换**，不要局部改。

```python
"""gate/eval.py —— 评测引擎。

跑法：
    python -m gate.eval --cases cases/tool_selection.json --sut fake --rounds 3
    python -m gate.eval --cases cases/tool_selection.json --sut real --rounds 3 --snapshot snapshots/real-v1

口径（写进 README，面试必问）：
    tool_acc  工具选对的比例             = tool_ok / n
    args_acc  工具选对时参数也对的比例    = args_ok / tool_ok      ← 条件口径，分母不是 n
    both_acc  一次调用整体正确            = both_ok / n
"""

from __future__ import annotations

import argparse
import json
import statistics
import sys
from pathlib import Path
from typing import Callable

Predict = Callable[[dict], dict]


def ensure_utf8() -> None:
    """Windows 控制台默认 GBK，打印 ✅/→ 会 UnicodeEncodeError。入口调一次。"""
    for stream in (sys.stdout, sys.stderr):
        try:
            stream.reconfigure(encoding="utf-8")
        except Exception:
            pass


def score_once(cases: list[dict], predict: Predict) -> dict:
    """跑一轮：逐题判分，返回计数 + 三个准确率 + 每题明细。"""
    tool_ok = args_ok = both_ok = 0
    detail: list[dict] = []

    for case in cases:
        pred = predict(case) or {}
        called = pred.get("tool")
        got_args = pred.get("args") or {}
        expect_args = case.get("expected_args") or {}

        t_ok = called == case.get("expected_tool")
        # 参数只在「工具选对」时才有意义：工具都错了，填对参数是运气不是能力
        a_ok = bool(t_ok and all(got_args.get(k) == v for k, v in expect_args.items()))
        b_ok = bool(t_ok and a_ok)

        tool_ok += int(bool(t_ok))
        args_ok += int(a_ok)
        both_ok += int(b_ok)
        detail.append({"id": case.get("id"), "expected": case.get("expected_tool"),
                       "actual": called, "tool_ok": bool(t_ok), "args_ok": a_ok})

    n = len(cases) or 1
    return {
        "n": len(cases),
        "tool_ok": tool_ok,
        "args_ok": args_ok,
        "both_ok": both_ok,
        "tool_acc": tool_ok / n,
        "args_acc": (args_ok / tool_ok) if tool_ok else 0.0,   # ← 条件分母
        "both_acc": both_ok / n,
        "detail": detail,
    }


def summarize(runs: list[dict]) -> dict:
    """多轮汇总：均值 + [min,max]。单轮的 ±8pp 噪声比要检测的退化还大（lab_05 实测）。"""
    def agg(key: str) -> dict:
        vals = [r[key] for r in runs]
        return {"mean": statistics.mean(vals), "min": min(vals), "max": max(vals)}

    return {"rounds": len(runs), "tool": agg("tool_acc"), "args": agg("args_acc"),
            "both": agg("both_acc")}


def build_predictor(sut: str, snapshot: str, fake_answers: str) -> Predict:
    if sut == "fake":
        table = json.loads(Path(fake_answers).read_text(encoding="utf-8"))

        def _fake(case: dict) -> dict:
            return table.get(case.get("id"), {"tool": "unknown", "args": {}})

        return _fake

    # 只有真模型这条路才 import langchain —— 保证 --sut fake 不需要装任何模型依赖
    from sut.agent import run_real_agent

    def _real(case: dict) -> dict:
        return run_real_agent(case["input"], snapshot_dir=snapshot)

    return _real


def _fmt(a: dict) -> str:
    return f"{a['mean']:.2%} [{a['min']:.2%}, {a['max']:.2%}]"


def main(argv: list[str] | None = None) -> int:
    ensure_utf8()
    ap = argparse.ArgumentParser(prog="gate.eval", description="跑测试用例，算工具/参数准确率")
    ap.add_argument("--cases", required=True, help="考卷 JSON")
    ap.add_argument("--sut", choices=["fake", "real"], default="fake")
    ap.add_argument("--snapshot", default="snapshots/real-v1", help="用哪个快照当工具集")
    ap.add_argument("--fake-answers", default="cases/fake_answers.json",
                    help="fake 版答案表（验证评测管线本身，不是模型成绩）")
    ap.add_argument("--rounds", type=int, default=3, help="轮次（>=3，单轮不可信）")
    ap.add_argument("--out-dir", default="reports")
    args = ap.parse_args(argv)

    cases = json.loads(Path(args.cases).read_text(encoding="utf-8"))
    predict = build_predictor(args.sut, args.snapshot, args.fake_answers)

    print(f"=== 评测：{len(cases)} case × {args.rounds} 轮，sut={args.sut} ===")
    runs = [score_once(cases, predict) for _ in range(args.rounds)]
    summary = summarize(runs)

    print(f"  tool_acc  {_fmt(summary['tool'])}   工具选对 / n")
    print(f"  args_acc  {_fmt(summary['args'])}   参数填对 / 工具选对   ← 条件口径")
    print(f"  both_acc  {_fmt(summary['both'])}   一次调用整体正确 / n")

    if args.sut == "fake":
        print("  fake 版只验证评测管线（分数应为 100%），不代表模型能力")

    out = Path(args.out_dir)
    out.mkdir(parents=True, exist_ok=True)
    report = {
        "sut": args.sut,
        "snapshot": args.snapshot,
        "cases": str(args.cases),
        "n": len(cases),
        "rounds": args.rounds,
        "tool_acc": round(summary["tool"]["mean"], 4),
        "args_acc": round(summary["args"]["mean"], 4),
        "both_acc": round(summary["both"]["mean"], 4),
        "tool_range": [round(summary["tool"]["min"], 4), round(summary["tool"]["max"], 4)],
        "args_range": [round(summary["args"]["min"], 4), round(summary["args"]["max"], 4)],
        "per_case": runs[-1]["detail"],
    }
    dest = out / f"eval_{Path(args.snapshot).name}_{args.sut}.json"
    dest.write_text(json.dumps(report, ensure_ascii=False, indent=2), encoding="utf-8")
    print(f"  已写入 {dest}")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
"""sut/agent.py —— LangGraph SUT（工具来自快照，不连真 server，保证可复现）。"""
import json
import os
from pathlib import Path
from typing import Any

from dotenv import load_dotenv
from langchain.agents import create_agent              # langchain 1.x；装的是 1.2.0
from langchain_core.tools import StructuredTool
from langchain_openai import ChatOpenAI
from pydantic import create_model

load_dotenv()
_LLM = ChatOpenAI(
    model="deepseek-flash",
    api_key=os.environ.get("DEEPSEEK_API_KEY", ""),
    base_url="https://api.deepseek.com",
    extra_body={"thinking": {"type": "disabled"}},     # DeepSeek 带 tools 必须关思考
)


def _lc_tools(tools: dict) -> list[StructuredTool]:
    """快照里的 JSON Schema → LangChain Tool。函数体只回 'ok'：
    评测只关心「模型想调哪个工具、参数是什么」，不关心工具真实执行结果。
    """
    out: list[StructuredTool] = []
    for name, info in tools.items():
        schema = info.get("input_schema") or {}
        props = schema.get("properties") or {}
        required = set(schema.get("required") or [])
        fields: dict[str, tuple[type, Any]] = {}
        for key in props:
            fields[key] = (Any, ... if key in required else None)
        args_model = create_model(f"{name}_args", **fields) if fields else None

        out.append(StructuredTool.from_function(
            func=lambda **_: "ok",                      # stub：不真执行
            name=name,
            description=info.get("description") or "",
            args_schema=args_model,
        ))
    return out


def run_real_agent(query: str, snapshot_dir: str = "snapshots/real-v1") -> dict:
    tools = json.loads((Path(snapshot_dir) / "tools.json").read_text(encoding="utf-8"))
    agent = create_agent(model=_LLM, tools=_lc_tools(tools))
    result = agent.invoke({"messages": [("human", query)]})

    for msg in reversed(result["messages"]):
        calls = getattr(msg, "tool_calls", None)
        if calls:
            first = calls[0]
            return {"tool": first["name"], "args": first.get("args") or {}}
    return {"tool": "unknown", "args": {}}
```

### 5.3 骨架（复用 §3 的新 `eval.py`，不要重写判分）

```python
"""gate/impact.py —— 漂移 → 重跑 → 影响面。核心：只重跑「受影响的 case」。"""
from __future__ import annotations

import argparse
import json
from pathlib import Path

from .eval import build_predictor, score_once
from .rules import ORDER

SEV_OK = {"BREAKING", "RISKY"}


def changed_tools(report: dict) -> dict[str, str]:
    """从 report.json 里挑出「严重度 >= RISKY」的工具 → 最严重的那档。"""
    out: dict[str, str] = {}
    for f in report.get("findings", []):
        if f["severity"] not in SEV_OK:
            continue
        cur = out.get(f["tool"])
        if cur is None or ORDER[f["severity"]] > ORDER[cur]:
            out[f["tool"]] = f["severity"]
    return out


def affected_cases(cases: list[dict], tools: set[str]) -> list[dict]:
    """case 的 expect_tool 落在变更工具里 → 这条 case 受影响。"""
    return [c for c in cases if c.get("expected_tool") in tools]


def main(argv: list[str] | None = None) -> int:
    ap = argparse.ArgumentParser(prog="gate.impact")
    ap.add_argument("--report", default="reports/report.json")
    ap.add_argument("--cases", default="cases/tool_selection.json")
    ap.add_argument("--base", required=True, help="旧快照目录")
    ap.add_argument("--head", required=True, help="新快照目录")
    ap.add_argument("--sut", choices=["fake", "real"], default="fake")
    ap.add_argument("--fake-answers", default="cases/fake_answers.json")
    ap.add_argument("--out", default="reports/impact.md")
    args = ap.parse_args(argv)

    report = json.loads(Path(args.report).read_text(encoding="utf-8"))
    cases = json.loads(Path(args.cases).read_text(encoding="utf-8"))
    tools = changed_tools(report)
    subset = affected_cases(cases, set(tools))

    if not subset:
        print("没有 case 命中变更工具，影响面为空（这本身是个有效结论）")
        return 0

    # 同一批 case，只换 schema → 这就是「配对比较」
    base_pred = build_predictor(args.sut, args.base, args.fake_answers)
    head_pred = build_predictor(args.sut, args.head, args.fake_answers)
    base = score_once(subset, base_pred)
    head = score_once(subset, head_pred)

    flipped = [d["id"] for d, b in zip(head["detail"], base["detail"])
               if b["tool_ok"] and not d["tool_ok"]]

    print("=== 影响面归因 ===")
    print("变更工具：" + " ".join(f"{k}({v})" for k, v in tools.items()))
    print("命中 case：" + ", ".join(c["id"] for c in subset))
    print(f"tool_acc  {base['tool_acc']:.2%} → {head['tool_acc']:.2%}"
          f"   Δ {(head['tool_acc'] - base['tool_acc']) * 100:+.2f}pp")
    print(f"args_acc  {base['args_acc']:.2%} → {head['args_acc']:.2%}"
          f"   Δ {(head['args_acc'] - base['args_acc']) * 100:+.2f}pp")
    print("受影响 case（head 里由对变错）：" + (", ".join(flipped) or "无"))

    md = [
        "## 影响面归因", "",
        "- 变更工具：" + " ".join(f"`{k}`({v})" for k, v in tools.items()),
        f"- 命中 case：{', '.join(c['id'] for c in subset)}",
        f"- **tool_acc**：{base['tool_acc']:.2%} → {head['tool_acc']:.2%}"
        f"（**Δ {(head['tool_acc'] - base['tool_acc']) * 100:+.2f}pp**）",
        f"- **args_acc**：{base['args_acc']:.2%} → {head['args_acc']:.2%}"
        f"（**Δ {(head['args_acc'] - base['args_acc']) * 100:+.2f}pp**）",
        f"- **受影响 case**：{', '.join(flipped) or '无'}",
    ]
    dest = Path(args.out)
    dest.parent.mkdir(parents=True, exist_ok=True)
    dest.write_text("\n".join(md) + "\n", encoding="utf-8")     # 覆盖写，不 append
    print(f"已写入 {dest}")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

**三个关键设计（面试要能讲）**：

1. **只跑受影响的 case**：变更 20 个工具里的 2 个时，不需要重跑全部 case；这也让"影响面"变成一句**具体的句子**而不是一个总数。
2. **配对比较**：同一批 case、同一个 SUT、只换 schema —— 这才是"变差了 12 个点"的合法来源（lab_05 的结论）。
3. **覆盖写 `impact.md`，不 append**：`report.md` 每次 `gate.check` 都会重写，append 的内容会丢；将来要做的是让 `check.py` 调用 `impact`，把这一节**渲染进** `report.md`。

## 10. 做完之后，你应该能说出这 5 句（面试）

1. **「我把漏判从 5/6 修到 6/6」** —— 具体形态是 JSON Schema 里**没写 `enum`/`type` 等于不限**，所以"从无到有"就是收紧；我一开始只比了"两边都存在"的键。
2. **「我顺手修了一个误报」** —— `{"type":"string"}` → `["string","null"]` 是放宽，不该拦；把 `type` 当成集合比（去掉成员才是破坏）就对了。
3. **「我的评测报三个数，不是一个」** —— `tool_acc` / `args_acc`(条件) / `both_acc`；只看一个总分时，`tool 0.9/args 0.1` 和 `tool 0.1/args 0.9` 是一模一样的。
4. **「我跑 3 轮报区间」** —— 20 个 case 时单轮的标准差约 8pp，比我要检测的 5pp 退化还大。
5. **「我的门禁只重跑受影响的 case」** —— 漂移 2 个工具时，我把 `expect_tool` 命中的 case 抽出来做配对比较，报的是"哪几条从对变错"，不是一个孤立的准确率。

> 最后一条尤其要说清楚：**别人报"准确率掉了 12%"是没法归因的；你报"c03/c07 从对变错"才是影响面。**
